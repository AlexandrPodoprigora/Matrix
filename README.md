# Laboratornye_OOP — лаба 2 «Матрица: продолжение»

Разноцветные «змейки» из символов, которые ползут **справа налево** по окну консоли Windows.
В отличие от лабы 1, добавлен параметр **частоты генерации линий**: в каждую секунду появляется
заданное количество линий в случайные моменты времени.
Выход — клавиша **Esc**.

## Задание
Доработать программу «Матрица»: добавить четвёртый параметр — частоту появления линий
(1–30 линий в секунду). Параметры: частота, скорость, длина линий, режим эпилепсии.
Моменты появления линий внутри секунды выбираются случайно, логика работает без потоков.

Вариант: направление — справа налево, форма линии — ромб,
режим эпилепсии — случайный цвет для каждой линии целиком.

## Запуск
Готовый `matrix.exe` лежит в папке. Запускай из `cmd` или PowerShell
(не из терминала MSYS2):

```
matrix.exe                    диалоговый режим (запросит 4 параметра)
matrix.exe 3 23 8 Y           частота 3, скорость 23, длина 8, режим эпилепсии
matrix.exe --help             справка
```

| Параметр | Значение | Описание |
|----------|----------|----------|
| частота  | 1–30     | линий в секунду |
| скорость | 1–30     | символов в секунду |
| длина    | 1–30     | символов в линии |
| эпилепсия| Y / N    | случайный цвет линий (Y) или зелёный (N) |

Некорректный ввод отклоняется: в диалоговом режиме параметр запрашивается заново,
в CLI выводится справка.

## Особенности решения
- `Symbol` — один символ: позиция, значение, цвет; умеет рисоваться и стираться.
- `Line` — линия сама управляет своим движением и скоростью: метод `update(currentTimeMs)`
  выполняет все шаги, время которых уже наступило (рисует новую голову, стирает хвост).
- `AppManager` — раз в секунду генерирует `частота` случайных моментов из диапазона 0–999 мс,
  сортирует их и создаёт линии, когда момент наступает; обновляет линии и удаляет завершившиеся.
- `Console` — служебный класс для работы с WinAPI (вывод в буфер консоли, цвета, время, клавиши).
- Без потоков: один главный цикл в `AppManager::run`.
- Память в стиле C++: `std::unique_ptr`, `std::make_unique`, `std::vector`, без ручных `new`/`delete`.

## Сборка
- **MinGW / MSYS2:** `build.bat` или `mingw32-make`
  (из терминала MSYS2: `g++ -std=c++17 -O2 -static -o matrix.exe src/*.cpp`)
- **Visual Studio:** создать пустой консольный проект C++17, добавить все файлы из `src/`, собрать.
